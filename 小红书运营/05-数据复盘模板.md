# 05-数据复盘模板

> 主题：如何用 AI 进行数据分析
> 说明：每周/每月运营数据复盘模板，用于评估效果、发现问题、迭代策略。

---

## 一、复盘周期

- **周复盘**：每周一，复盘上周数据，调整本周排期。
- **月复盘**：每月初，复盘整月数据，更新选题库与策略。

---

## 二、核心指标

| 指标 | 定义 | 目标 | 实际 | 差距 |
|------|------|------|------|------|
| 笔记发布量 | 本周发布篇数 | 3-4 篇 |  |  |
| 总曝光 | 所有笔记曝光之和 | 持续增长 |  |  |
| 平均互动率 | (赞+藏+评)/阅读 | ≥ 5% |  |  |
| 平均收藏率 | 收藏/阅读 | ≥ 3% |  |  |
| 涨粉数 | 净增粉丝 | 月增 500+ |  |  |
| 引流咨询 | 评论区/私信咨询量 | 持续增长 |  |  |
| 注册转化 | 咨询→注册 | 持续优化 |  |  |

---

## 三、单篇笔记复盘

| 维度 | 问题 | 结论 |
|------|------|------|
| 选题 | 是否命中目标人群痛点？ |  |
| 标题 | 是否埋了关键词、有吸引力？ |  |
| 封面/配图 | 是否清晰、信息密度高？ |  |
| 正文 | 是否有痛点开头、步骤拆解、价值结尾？ |  |
| 标签 | 是否带核心标签 + 差异化标签？ |  |
| 发布时间 | 是否在黄金时间？ |  |
| 评论区 | 是否置顶引流、及时回复？ |  |
