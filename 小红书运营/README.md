# 小红书运营模块

> 主题：**如何用 AI 进行数据分析**
> 归属项目：数据分析智能体（dataAnalysisAgent）
> 定位：围绕「AI 数据分析」这一主题，为产品在小红书平台建立内容运营阵地，实现品牌曝光、用户引流与产品转化。

---

## 一、模块定位

本模块是产品在小红书平台的**内容运营与增长阵地**，核心主题锁定为 **「如何用 AI 进行数据分析」**。

- **内容主线**：教用户用 AI 工具做数据分析（问卷分析、统计、报告、可视化等），把产品能力自然植入内容。
- **转化路径**：干货内容 → 评论区/主页引导 → 产品注册 → 免费额度体验 → 付费转化。
- **与产品关系**：产品是「数据分析智能体」，小红书内容就是它的「说人话版说明书 + 引流入口」。

## 三、核心主题拆解

「如何用 AI 进行数据分析」可拆解为以下内容支柱：

| 支柱 | 内容方向 | 对应产品能力 |
|------|---------|-------------|
| **AI 问卷分析** | 用 AI 做信效度、相关性、差异检验 | 统计诊断引擎 |
| **AI 报告生成** | 一键生成可写进论文/汇报的报告 | 报告导出（Word/Excel/PDF/PPT） |
| **AI 数据可视化** | 用 AI 把数据变成图表 | 报告页 SVG 可视化 |
| **AI 预演** | 发问卷前用 AI 模拟数据验证设计 | 模拟预演引擎 |
| **AI 诊断** | 用 AI 说人话解释统计结果 | R4 智能诊断 |
| **AI 提效** | 用 AI 替代重复性数据分析工作 | 全产品 |

---

## 四、使用说明

1. **新运营人员**：先读 `01-运营策略.md` 了解定位，再读 `02-内容选题库.md` 选选题。
2. **写文案**：从 `03-文案模板库.md` 套用标题公式与正文模板。
3. **排期发布**：用 `04-发布排期表.md` 规划每周内容。
4. **复盘迭代**：每周用 `05-数据复盘模板.md` 复盘，反哺选题库。

## 五、与现有推广素材的关系

项目 `docs/推广素材/` 下已有 `小红书文案.md`（产品推广文案集）与 01~08 配图。本模块在其基础上**升级为系统化运营体系**：

- `docs/推广素材/小红书文案.md` → 单篇文案集（产品向）
- `小红书运营/` → 完整运营模块（主题向：AI 数据分析）

两者互补：产品向文案用于直接种草，主题向内容用于建立「AI 数据分析」专业心智并长期引流。
