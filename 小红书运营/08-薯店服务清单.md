# 小红书店铺（薯店）可售卖服务清单

> 主题：如何用 AI 进行数据分析
> 定位：薯店是「数据分析智能体」产品的**人工服务承接端**，产品负责自动获客 + 自助跑通，薯店承接复杂/代做需求。
> 说明：本清单基于产品能力（模拟数据生成、预演、信效度分析、报告生成、R4 诊断）设计，可逐步上架。

---

## ⚠️ 一、合规与学术诚信（必读，先看这里）

> **最重要的一条：本薯店及产品坚决反对学术造假。** 所有服务只做「数据生成与统计辅助」，绝不做论文代写、绝不伪造真实数据、绝不帮助造假。以下内容必须体现在薯店商品页、笔记文案和交付物中。

### 1.1 学术诚信红线（必须遵守）

| 红线 | 说明 |
|------|------|
| **不伪造真实数据** | 模拟数据必须明确标注 `simulated`，不得冒充真实数据，不得用于正式学术论文 |
| **不代写论文** | 只提供数据生成与统计服务，不代写研究结论、不代写论文 |
| **不帮助造假** | 不协助把模拟数据包装成真实数据提交，不协助学术不端 |
| **不承诺结果** | 不承诺"包过答辩""保证显著"，避免误导与违规 |
| **数据来源透明** | 交付物必须标注数据来源（模拟/真实），与产品合规机制一致 |

### 1.2 产品可以用来做什么（合法用途）

「数据分析智能体」及薯店服务，是**研究预演与教育工具**，合法用途包括：

- **问卷设计验证**：发问卷前，用模拟数据预演，验证题目设计、信效度能否达标。
- **统计方法学习**：用模拟数据练习信效度、相关、差异检验等统计方法。
- **研究方案预演**：在正式收集数据前，模拟数据跑通分析流程，优化研究设计。
- **教学演示**：用模拟数据做课堂演示、方法讲解。
- **真实数据辅助分析**：对你自己收集的**真实数据**做统计分析、生成报告。
- **数据分析提效**：用 AI 辅助完成重复性统计工作，节省时间。

### 1.3 如何推进自己的真实数据（引导用户）

薯店和产品应**引导用户走向真实数据**，而非依赖模拟数据：

1. **模拟数据只用于预演**：明确告知用户，模拟数据仅用于验证设计、练习方法，**不能替代真实数据**。
2. **用预演优化问卷**：先用模拟数据预演，发现题目问题 → 修改问卷 → 再正式发放。
3. **正式收集真实数据**：问卷定稿后，通过正规渠道发放，收集真实样本。
4. **真实数据做正式分析**：用产品/薯店服务对真实数据做信效度、相关、差异检验，生成正式报告。
5. **模拟数据与真实数据分离**：交付物明确区分，模拟数据带 `simulated` 标识，真实数据带 `real` 标识。

> **薯店引导话术**：
> 「模拟数据只用来预演和练手，正式论文一定要用你自己收集的真实数据。先用模拟数据把问卷设计调好，再正式发放，这样真实数据一次就能跑通。」

### 1.4 法律与平台合规（避开风险）

| 风险点 | 规避措施 |
|--------|---------|
| **学术不端** | 商品页、笔记、交付物均声明"模拟数据不得用于正式学术论文" |
| **虚假宣传** | 不承诺"包过""保证显著""代写论文" |
| **数据造假** | 交付物强制标注数据来源，模拟数据带 `simulated` 标识 |
| **隐私/数据安全** | 不收集、不泄露用户问卷中的敏感个人信息 |
| **平台规则** | 避免硬广、导流外链，用"搜索工具名"方式引导；薯店商品描述合规 |
| **知识产权** | 不盗用他人问卷/量表，涉及版权量表需用户自行确认授权 |

### 1.5 薯店商品页合规声明（模板）

> **服务声明**：本服务提供的是**数据生成与统计辅助**，所有模拟数据均带 `simulated` 标识，**仅用于研究预演、方法学习与教学演示，不得用于正式学术论文或任何学术不端行为**。正式研究请使用您自己收集的真实数据。本店不提供论文代写服务，不承诺任何学术结果。

## 二、服务设计原则

1. **从现有能力出发**：你目前已有「模拟数据生成」服务，先把它做深做透，再逐步扩展。
2. **产品 + 人工双路径**：简单需求引导用产品自助（免费/19.9 元），复杂需求转薯店人工（100~500 元/单）。
3. **合规红线**：只做「数据生成与统计服务」，不做论文代写；所有模拟数据带 simulated 标识；引导用户走向真实数据。
4. **客单价爬坡**：从 19.9 元（产品自助）→ 100~500 元（人工服务）→ 更高（复杂定制）。

## 三、服务详情

### 服务 1：模拟数据生成（现有核心服务）

**一句话**：根据你的问卷题目和需求，生成符合预期趋势的样本数据。

**适用场景**：
- 发问卷前，用模拟数据预演，验证问卷设计能否跑出预期统计结果
- 想验证信效度、相关关系能否达标，再决定是否正式发放
- 需要特定样本量、特定相关关系的模拟数据做方法练习/教学演示

> ⚠️ **合规提示**：模拟数据**仅用于预演、方法学习与教学演示**，带 `simulated` 标识，**不得用于正式学术论文**。正式研究请使用真实数据。

**交付物**：
- 模拟数据集 Excel（N × 题目数，带 simulated 标识）
- 维度间相关矩阵
- 各维度均值、标准差、α 系数、KMO 统计摘要
- 生成说明（假设路径、样本量、量表级数）
- 合规声明（数据来源标注 + 免责声明）

**定价**：50~150 元/份（按样本量、题目数、复杂度浮动）

**下单需提供**：
- 问卷题目（或量表）
- 目标样本量 N
- 期望的相关关系/趋势（如"工作压力与职业倦怠正相关"）
- 量表级数（5 点/7 点）
- 用途说明（预演/学习/教学，用于合规判断）

**与产品关系**：产品「模拟数据生成引擎」可自助生成（免费额度），薯店人工服务承接"需要定制、需要保证达标、没时间自己跑"的用户。**交付时引导用户：模拟数据只用于预演，正式论文用真实数据。**

---

### 服务 2：问卷题目体检

**一句话**：帮你检查问卷题目设计有没有问题，避免发出去才发现信效度不行。

**适用场景**：
- 问卷还没发，想先检查题目质量
- 导师说"题目有问题"，但不知道哪里有问题

**交付物**：
- 题目问题清单（题量、维度划分、反向题、表述问题）
- 修改建议

**定价**：30~80 元/份

**与产品关系**：产品「题目体检引擎」可自助，薯店人工承接"需要人工把关、需要详细建议"的用户。

---

### 服务 3：问卷预演验证

**一句话**：发问卷前先用 AI 模拟数据预演，验证问卷能不能跑出预期结果。

**适用场景**：
- 发问卷前想确认信效度会不会达标
- 想提前知道样本量够不够、相关关系能不能显著

**交付物**：
- 预演报告（模拟数据统计结果）
- 信效度预判 + 样本量建议
- 风险提示（哪些维度可能不达标）

**定价**：80~200 元/份

**与产品关系**：这是产品**独家差异化卖点**（竞品没有），薯店人工服务承接"需要专业解读预演结果"的用户。

---

### 服务 4：信效度分析

**一句话**：帮你跑信效度分析，告诉你问卷靠不靠谱。

**适用场景**：
- 问卷回收后，需要信效度分析
- 信效度不达标，需要诊断和解决建议

**交付物**：
- 信效度分析报告（α 系数、KMO、Bartlett、因子分析）
- 结论 + 不达标时的解决建议

**定价**：100~300 元/份

**与产品关系**：产品可自助跑信效度，薯店人工承接"需要解读、需要解决建议"的用户。

---

### 服务 5：完整数据分析报告

**一句话**：帮你把问卷数据完整分析，生成可直接用的统计报告。

**适用场景**：
- 数据回收了，需要完整分析（描述统计 + 信效度 + 相关 + 差异 + 回归）
- 需要一份能写进论文的规范报告

**交付物**：
- 完整统计报告（Word/PDF）
- 三线表、图表
- 统计结果规范化描述（可直接参考写进论文）

**定价**：200~500 元/份

**与产品关系**：产品可自助生成报告并导出，薯店人工承接"需要完整、规范、可直接用"的用户。

---

### 服务 6：数据救急/诊断

**一句话**：数据跑不通、结果不显著、信效度不达标？帮你诊断并给方案。

**适用场景**：
- 答辩前数据跑不通
- 结果不显著，不知道怎么办
- 信效度不达标，导师让重做

**交付物**：
- 问题诊断（哪里出了问题）
- 解决方案（调整题目/样本/方法）
- 可执行建议

**定价**：100~300 元/次

**与产品关系**：产品「R4 诊断引擎」可自助，薯店人工承接"需要人工兜底、需要确定方案"的用户。这是**利润池**，客单价高。

---

### 服务 7：复杂统计定制

**一句话**：中介效应、调节效应、SEM 等复杂分析，人工定制。

**适用场景**：
- 需要中介/调节效应分析
- 需要结构方程模型（SEM）
- 需要更复杂的统计方法

**交付物**：
- 定制分析结果
- 完整报告 + 方法说明

**定价**：300~800 元/单

**与产品关系**：产品当前没有中介/调节/SEM 功能，这是**纯人工服务**，客单价最高，也是产品未来功能补位的方向。
