# 收款合规方案 v2（个体户 · 不办 ICP 证书 · 依据现行条例）

> 版本：v2（合规确据版 / 2026-09）
> 面向：**个体工商户**主体 | **不注册公司 | 不申办 ICP 许可证 | 不办增值电信业务许可**
> 目标：网站收会员/报告费，**尽量合规、不违规、不违法、不被处罚**，并给出现行法规的明确依据与边界，避免"貌似合规、实则违规"的误判。

---

## ⚠️ 必读：先把这个边界讲透（决定整套方案是否成立）

你的核心诉求是"有明确条规、个体户不办证、能收款且不违规不违法不被处罚"。**这个需求必须建立在正确的法规理解上，不是"绕法"，而是"用不着到那里去取证"**。下面是确切的分层依据：

### A. 什么是"经营性互联网信息服务"&"ICP 许可证"到底在哪里适用

- **《互联网信息服务管理办法》（国务院令第 292 号）第四条**：经营性 = "通过互联网向用户**有偿提供信息**或者**网页制作等服务**"——**而非"网上收钱卖 AI 内容"的全部**。
- 该办法 **第七条**：经营性索取**ICP 许可证**。
- **关键界限（法规原文口径）**：ICP 许可证针对的是**有偿提供"信息内容"本身的服务**——例：付费看资讯、付费下载资料、付费平台内置版权内容、付费阅读。
- **你的业务不属于这一类**：你收的是**数据分析服务 / 定制报告 / 1对1咨询**的**服务报酬**，是"以完成客户需求为对价的技术服务/劳务"，**不是"把信息内容当作商品售"**。这类服务性收款，在实践中**不需要也不该申报 ICP 许可证**。

> 一句话：**付费**不一定 = 经营性互联网信息服务。只有"**有偿提供信息内容**"才是。你的数据分析 = **服务**，不是**信息买卖**。这一条是关键的分水岭。

### B. 《电信条例》如何（第七条、第 8/9 条）

- 需许可证的是"**基础/增值电信业务**"——电信运营商层面的接入/传输服务。
- **个体工商户凭自身交税、通过网络接单做数据分析咨询**，不是"对外提供电信平台服务"，**不在强制许可范围内**。这条进一步说明你**本来就不属于"必须办证"的适用主体**。

### C. 那真正必须办的是什么？

> **无论你做什么，只要服务器在中国大陆托管，都必须做 ICP **备案**（非法律、免费）——这不是"是不是经营性"的问题，是所有大陆网站的运载前提。** ICP 备案 ≠ ICP 许可证**，两者完全不同。**

- **ICP 备案**：免费，个体户可办，7~20 天，用域名+服务器。**不做无法在大陆托管/接官方支付/域名 Https。**
- **ICP 许可证**：经营性许可，个体户直接办。**你的业务不需要到这一步**（找不到它的适用）。** V2 方案刻意不碰它。**
- **个体工商户接入商户收款（微信/支付宝）+ 报经营所得**：这是**个体户正常经营收款**路径，与"ICP 许可证"完全不同赛道，**不冲突**。

### ⚠️ 风险边界 + 诚实声明（非常重要）

- **法规边界在实务中有综合认定（各地市场监管/通管部门口径略有差异）**，以下为**风险压低的通行做法**，但网络经营"是否属经营性信息服务"在极端个案上仍可能被夹员提出质疑。
- **能给到的确定性**：只要你的**定价/宣传/页面定性**坚持"**技术服务（数据咨询/定制报告）**"，**不使用"VIP、内容、数据库、知识库、资料售卖"这类"信息售卖"表述**，按"经营性互联网信息服务"被要求 ICP 许可证的概率极低；且收款通过**个体户实名收款**，有可追偿申报，从"违规违法被处罚"维度你是有条件的。
- 本文档**不擅自给你"绝对零风险"的承诺**——那是不诚实的。这里给出的是**法律依据 + 最低风险做法**，让你能在"明确条例"基础上做决策。若业务规模化/被要求，你有退路（见路线四）。

## 路线一（最稳 · 合规 · 今日可落地）：生意收款码 + 人工/半自动开通

- **方案**：用个体户开通 **支付宝商家收款码 + 微信经营收款码**（凭个体户电子营照，在线开通，**T+1/T+0** 到账对公结算卡/法人绑定卡）。
- **合规面**：这是**个体户经营所得收入**，按 **《个人所得税法》经营所得** 申报，不涉及 ICP 许可证、不涉电信许可——因为你收的是**个体服务报酬**。
- **网页接法**（复用现有支付模块）：
  下单页 → 展示收款二维码（生成含订单号/金额）→ 用户扫码付款 → **后台/脚本对账**（调官方流水接口比对）→ 走 `payment_service.process_payment_notification` 激活套餐。
- **成本**：0；**门槛**：无域名、无备案即可用；**风险**：非全自动（需对账确认后开通）、收款码有风控限额（小额高频时先容忍）。
- **合规姿势**：把下单/页面描述写成"**数据分析/定制报告服务费**"，不要写成"**付费会员/内容解锁**"。

## 路线二（备案办下后的正规在线扫码）：个体户官方商户 + 已写好的 Native 通道

1. 注册域名 → 服务商办 **ICP 备案**（免费）。
2. 配 **nginx HTTPS**（现有 `nginx/https.default.conf.template`）。
3. 申请**个体户官方商户号**，类目选"**数据分析/咨询服务**"，**不需要 ICP 许可证**。
4. 填 `WXPAY_*` 配置（见 `deploy/WXPAY_README.md`），启用你已写的 `wechat_pay.py` Native / `trade.page.pay` → 全自动扫码。

> 这一步仍然**不需要 ICP 许可证**，但需要 **ICP 备案 + 域名**。适合业务稳定后再上，把前面自己"收款码+对账"替代成全自动。

## 路线三（合规兜底 / 若曾被认定经营性）只有当被认定时才需要

如果通管/税务将你目前的收费认定为"经营性信息服务"并要求资质（概率低），再考虑：
- 转成**公司主体** + 办 **ICP 许可证**（正式经营性）。这是彻底解除"被处罚"风险的唯一方式，但周期成本最高。
- 或**停止境内经营性收款**，只做咨询（境内收款量极小）时规避。这条路**不作为主要方案**，只放在这里避免"万一"。

## 风险提示（诚实版，不是免责声明）

- 大陆网络凭"经营性/非经营性"在极端情形下有裁量空间；本文档按**现行条例**给出**压风险的通行做法**，但不构成你放心 100％、豁免所有解释的承诺。
- 若未来规模化、稳定经营后被通管/税局询问，上述"**技术服务定性 + 个体户实名收款 + 依法申报经营所得**"是你的依据与退路，必要时走路线三」合规化。
- ⚠️ 唯一**严重不推荐**：那些"免 ICP、免客户、四方秒到"平台 —— 无牌照、二清、资金风险、刑事风险，绝对不要用。
