# 变量类型与测量尺度

在统计分析中，正确识别变量类型是选择分析方法的前提。不同类型的变量，适用的统计方法完全不同。

## 变量的基本分类

### 自变量与因变量

- **自变量（Independent Variable）**：研究中主动操纵或选择的变量，用于解释或预测其他变量。
- **因变量（Dependent Variable）**：研究中想要解释或预测的结果变量。

例如：研究“学习动机对学业成绩的影响”，学习动机是自变量，学业成绩是因变量。

### 中介变量与调节变量

- **中介变量（Mediator）**：解释自变量如何影响因变量的内部机制。
- **调节变量（Moderator）**：影响自变量与因变量之间关系强度或方向的变量。

## 测量尺度的四种类型

### 1. 定类尺度（Nominal）

用于分类，无大小顺序。

- 例子：性别（男/女）、专业（文科/理科）
- 适用统计：频率、卡方检验

### 2. 定序尺度（Ordinal）

可以排序，但间距不等。

- 例子：学历（小学/中学/大学）、满意度等级
- 适用统计：中位数、秩和检验

### 3. 定距尺度（Interval）

间距相等，但无绝对零点。

- 例子：温度（摄氏度）、Likert 量表得分
- 适用统计：均值、标准差、t 检验

### 4. 定比尺度（Ratio）

间距相等，有绝对零点，可以进行比值运算。

- 例子：身高、体重、收入
- 适用统计：所有统计方法

## 连续变量与分类变量

| 类型 | 说明 | 例子 |
|------|------|------|
| 连续变量 | 可取无限多个值 | 年龄、成绩、收入 |
| 分类变量 | 取有限个类别 | 性别、年级、是否 |

## 为什么变量类型很重要？

错误识别变量类型会导致：

- 选择了不适用的统计方法
- 结果解释出现偏差
- 论文被质疑方法学不严谨

## 小结

在论文中，建议在“研究方法”部分明确说明每个变量的类型和测量尺度，这会让你的研究更加规范、可信。
