# APA 格式速查

APA（American Psychological Association）格式是社会科学论文中最常用的统计结果报告规范。本文整理了问卷研究中最常用的 APA 格式要求。

## 统计符号规范

### 斜体与正体

| 符号 | 含义 | 格式 |
|------|------|------|
| $M$ | 均值 | 斜体大写 |
| $SD$ | 标准差 | 斜体大写 |
| $N$ | 总样本量 | 斜体大写 |
| $n$ | 子样本量 | 斜体小写 |
| $r$ | 相关系数 | 斜体小写 |
| $p$ | 显著性水平 | 斜体小写 |
| $t$ | t 统计量 | 斜体小写 |
| $F$ | F 统计量 | 斜体大写 |
| $\chi^2$ | 卡方统计量 | 斜体小写 + 上标 |
| $\alpha$ | 显著性水平 | 斜体小写希腊字母 |
| $\beta$ | 回归系数 | 斜体小写希腊字母 |

> **规则**：所有统计量符号使用斜体；下标用正体（如 $M_{\text{male}}$）。

### 小数位数

| 统计量 | 建议小数位 |
|--------|----------|
| $M$、$SD$ | 2 位 |
| $r$、$t$、$F$ | 2 位 |
| $p$ | 3 位（如 $p = 0.003$） |
| $\chi^2$ | 2 位 |
| 效应量（$d$、$\eta^2$） | 2 位 |

> **注意**：$p$ 值小于 0.001 时报告为 $p < 0.001$，不报告 $p = 0.000$。

## 显著性标注

APA 第七版建议报告精确 $p$ 值，不再使用星号标注系统：

| 旧版标注 | 新版建议 |
|---------|---------|
| $p < 0.05$* | $p = 0.032$ |
| $p < 0.01$** | $p = 0.006$ |
| $p < 0.001$*** | $p < 0.001$ |
| ns | $p = 0.123$ |

> 但许多期刊仍接受星号标注，请根据目标期刊要求调整。

## 常见统计结果的 APA 写法

### 描述统计

> 参与者年龄范围为 18-24 岁（$M = 20.35$, $SD = 1.42$），其中男生 120 人（$n = 120$），女生 180 人（$n = 180$）。

### 信效度

> 本问卷总体 Cronbach's $\alpha = 0.85$，各维度 $\alpha$ 系数在 0.72-0.88 之间，信度良好。KMO = 0.82，Bartlett 球形检验显著（$\chi^2 = 1234.56$, $df = 136$, $p < 0.001$），适合进行因子分析。

### 相关分析

> 学习动机与学业表现呈显著正相关（$r = 0.45$, $p < 0.01$），支持假设 H1。

相关矩阵表格中，建议在相关系数后用上标注明显著性：

| 变量 | 1 | 2 | 3 |
|------|---|---|---|
| 1. 学习动机 | — | | |
| 2. 学业表现 | 0.45** | — | |
| 3. 自我效能 | 0.38** | 0.52** | — |

> * $p < 0.05$, ** $p < 0.01$, *** $p < 0.001$

### 独立样本 t 检验

> 男生（$M = 3.45$, $SD = 0.62$）与女生（$M = 3.68$, $SD = 0.55$）在学习动机上的差异达到显著水平（$t(298) = 3.27$, $p = 0.001$, $d = 0.38$）。

### 配对样本 t 检验

> 前测（$M = 2.85$, $SD = 0.71$）与后测（$M = 3.42$, $SD = 0.65$）得分差异显著（$t(149) = 8.56$, $p < 0.001$, $d = 0.70$）。

### 单因素方差分析

> 不同年级学生在学习动机上存在显著差异（$F(3, 296) = 4.82$, $p = 0.003$, $\eta^2 = 0.05$）。事后检验（Tukey HSD）显示大一学生（$M = 3.72$, $SD = 0.58$）显著高于大四学生（$M = 3.31$, $SD = 0.64$）。

### 卡方检验

> 性别与选课偏好之间存在显著关联（$\chi^2(2, N = 300) = 12.34$, $p = 0.002$, Cramér's $V = 0.20$）。

### 线性回归

> 以学业表现为因变量，学习动机为自变量进行线性回归分析。模型显著（$F(1, 298) = 74.23$, $p < 0.001$），学习动机显著正向预测学业表现（$\beta = 0.45$, $t = 8.62$, $p < 0.001$），解释方差 $R^2 = 0.20$。

## 表格格式

### 基本要求

1. 表格不使用竖线，仅使用水平线
2. 表号和标题在表格上方
3. 注释在表格下方
4. 统计量符号斜体

### 示例

**Table 1**

*各维度描述统计与信度*

| 维度 | 题目数 | $M$ | $SD$ | $\alpha$ |
|------|--------|-----|------|---------|
| 学习动机 | 5 | 3.45 | 0.62 | 0.85 |
| 学业表现 | 6 | 3.68 | 0.55 | 0.88 |
| 自我效能 | 4 | 3.22 | 0.70 | 0.78 |

*Note.* $\alpha$ = Cronbach's alpha.

## 图表格式

### 基本要求

1. 图号和标题在图片下方
2. 坐标轴标签简洁明了
3. 误差线注明类型（如 95% CI）
4. 不使用图框

## 常见错误

| 错误 | 正确写法 |
|------|---------|
| p=0.032 | $p = 0.032$ |
| p<0.05 | $p = 0.032$（报告精确值） |
| M=3.45 | $M = 3.45$ |
| 3.45±0.62 | $M = 3.45$, $SD = 0.62$ |
| r=.45 | $r = 0.45$ |
| p=0.000 | $p < 0.001$ |

## 小结

- 统计符号一律斜体
- $p$ 值报告 3 位小数，小于 0.001 报告 $p < 0.001$
- 必须报告效应量（$d$、$\eta^2$、$r$ 等）
- 表格无竖线，图标题在下方
- 参考目标期刊的具体要求调整
