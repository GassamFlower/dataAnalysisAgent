# 探索性因子分析（EFA）

探索性因子分析（Exploratory Factor Analysis, EFA）是一种多元统计方法，用于揭示一组相对较多变量背后的潜在结构。它常用于量表开发，帮助研究者识别一组测量变量背后的潜在构念（latent constructs）。

## 什么是探索性因子分析

EFA 用于在**不预设因子结构**的情况下，从数据中探索潜在的因子维度。它基于共同因子模型，其中显性变量被表达为共同因子、独特因子和测量误差的函数。

**适用场景**：当研究者对因子或测量变量的模式**没有先验假设**时使用。

> 与验证性因子分析（CFA）的区别：开发量表时应先使用 EFA 探索因子结构，再进行 CFA 检验假设关系。

## 核心概念

### 因子载荷（Factor Loading）

- **定义**：因子载荷是项目（items）与因子之间的回归系数，衡量共同因子对测量变量的影响程度；
- **作用**：通过检查因子模式来确定哪些项目在哪些因子上载荷较高，从而为因子命名；
- **解释**：载荷越高，说明该测量变量与该因子的关系越密切。一般要求载荷 > 0.5 且交叉载荷 < 0.4。

### 特征值（Eigenvalue）

- **定义**：因子的特征值代表该因子所解释的变量方差量；
- **意义**：特征值越低，该因子对解释变量方差的贡献越小；
- **用途**：特征值在多种确定因子数量的方法中起核心作用（如 Kaiser 准则、碎石图、平行分析等）。

### 方差解释率（Variance Explained）

- **概念**：因子分析的目标是用较少的因子解释测量变量中的大部分方差；
- **应用**：研究者通过检查累积方差解释比例来评估因子解的充分性。一般要求累积方差解释率 > 60%。

## 确定因子数量的方法

| 方法 | 核心思路 |
|------|----------|
| **Kaiser 准则（K1 规则）** | 保留特征值大于 1 的因子数 |
| **碎石图（Scree Plot）** | 绘制特征值从大到小的曲线，观察最后一个大幅下降点之前的因子数 |
| **平行分析（Parallel Analysis）** | 将实际特征值与随机数据特征值比较，取交叉点之前的因子数（表现良好） |
| **最小平均偏相关（MAP）** | 逐步偏出主成分，取平均平方偏相关最低的步骤数 |

> Kaiser 准则具有任意性（特征值 1.01 被保留，0.99 被舍弃），常导致过度提取因子。现代方法（如平行分析）更受推荐。

## 旋转方法（Rotation Methods）

旋转用于帮助解释因子矩阵，因为对于两个或更多因子的解，存在无限多种方向都能同样好地解释数据。

### 正交旋转（Orthogonal Rotation）

- **特点**：约束因子之间相互垂直（不相关）；
- **优点**：简单、概念清晰；
- **缺点**：社会科学中构念往往相关，正交旋转可能不现实；
- **常见方法**：**Varimax（最大方差法）** 最常用，最大化因子载荷平方的方差，使每个变量尽可能与单一因子对应。

### 斜交旋转（Oblique Rotation）

- **特点**：允许因子之间存在相关；
- **优点**：当因子预期相关时，能产生更好的简单结构，并提供因子间相关的估计；
- **常见方法**：**Direct Oblimin**、**Promax**。

## 分析步骤

1. **适用性检验**：进行 KMO 检验（KMO > 0.6）和 Bartlett 球形检验（p < 0.05），确认数据适合做因子分析；
2. **提取因子**：选择提取方法（数据正态时推荐最大似然法 ML，否则推荐主轴因子法 PAF）；
3. **确定因子数量**：结合 Kaiser 准则、碎石图、平行分析等方法确定因子数；
4. **旋转**：选择正交旋转（Varimax）或斜交旋转（Promax/Oblimin）；
5. **解释因子**：根据因子载荷为各因子命名；
6. **评估**：检查累积方差解释率、因子载荷是否达标。

## 注意事项

1. **EFA vs. CFA**：开发量表时应先使用 EFA，再进行验证性因子分析（CFA）以检验假设关系；
2. **提取方法选择**：数据正态分布时推荐最大似然法（ML）；正态性假设被违反时推荐主轴因子法（PAF）；
3. **理论的重要性**：EFA 若缺乏理论框架可能导致误导性解释；
4. **多方法收敛**：多种现代方法（如平行分析 + 比较数据法）结果一致时，因子数量估计的准确性可显著提高。

## 报告示例

> 采用主成分分析法提取因子，结合 Kaiser 准则和碎石图，共提取 3 个因子，累积方差解释率为 62.4%。经 Varimax 旋转后，各题项在所属因子上的载荷均大于 0.5，且无交叉载荷。根据题项内容，将三个因子分别命名为"学习动机""学习策略"和"学习投入"。

## 小结

探索性因子分析是量表开发和效度检验的重要方法。通过因子载荷、特征值、方差解释率和旋转方法等核心概念，可以识别测量变量背后的潜在结构。分析时应结合多种方法确定因子数量，并注意 EFA 与 CFA 的先后顺序。
