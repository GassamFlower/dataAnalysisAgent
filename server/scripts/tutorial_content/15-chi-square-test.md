# 卡方检验

卡方检验（Chi-Squared Test，χ² 检验）用于分析列联表中分类变量之间的关系，是问卷研究中分析分类变量关联最常用的方法。

## 卡方检验的原理

卡方检验通过比较**实际观测频数**与**理论期望频数**之间的差异来判断变量间的关系：

- 如果观测值与期望值差异**小** → 差异可能是随机误差所致 → 不能拒绝原假设（变量独立）；
- 如果观测值与期望值差异**大** → 差异不太可能由随机误差造成 → 拒绝原假设（变量相关）。

检验统计量公式：

\[
X^2 = \sum_{i=1}^{k} \frac{(x_i - m_i)^2}{m_i}
\]

其中：
- \( x_i \) = 第 \( i \) 类的实际观测次数
- \( m_i \) = 第 \( i \) 类的理论期望次数
- \( k \) = 分类总数

当原假设成立且样本量足够大时，该统计量趋近服从自由度为 \( (k-1) \) 的卡方分布。

## 适用场景

| 场景 | 说明 |
|------|------|
| **适配度检验**（Goodness of Fit） | 检验观测数据的分布是否符合某个理论分布 |
| **独立性检验** | 检验两个分类变量是否相互独立（最常用） |
| **同质性检验** | 检验不同总体的分类变量分布是否相同 |

### 适用条件

- 数据为**分类变量**（名义或有序）；
- 样本为随机抽样；
- 各分类**互斥**；
- 期望频数不宜过小（一般要求**每个格子的期望次数 ≥ 5**）。

## 卡方独立性检验

这是卡方检验最常用的形式，用于判断**两个分类变量是否独立**。

### 检验步骤

1. **建立原假设**：H₀：两个变量相互独立；
2. **建立备择假设**：H₁：两个变量不独立（存在关联）；
3. **计算期望频数**：基于独立性假设推算各格子的理论次数；
4. **计算卡方统计量**：比较观测值与期望值的差异；
5. **确定自由度**并查卡方分布表；
6. **做出判断**：若卡方值大于临界值（或 p 值 < 显著性水平），则拒绝原假设。

## 列联表

**列联表**（Contingency Table）是卡方检验的基础数据结构，用于展示两个分类变量的联合频数分布。

### 示例：2×2 列联表

|  | 类别 B₁ | 类别 B₂ | 合计 |
|--|--------|--------|------|
| **类别 A₁** | a | b | a+b |
| **类别 A₂** | c | d | c+d |
| **合计** | a+c | b+d | n |

### 期望频数计算

在独立性假设下，每个格子的期望频数为：

\[
m_{ij} = \frac{(\text{第 } i \text{ 行合计}) \times (\text{第 } j \text{ 列合计})}{\text{总样本量 } n}
\]

## 自由度

卡方检验的自由度取决于列联表的维度：

\[
\text{自由度} = (r - 1) \times (c - 1)
\]

其中 \( r \) = 行数，\( c \) = 列数。

### 常见情况

- **2×2 表**：自由度 = 1
- **3×2 表**：自由度 = 2
- **k 类适配度检验**：自由度 = k − 1

## 重要注意事项

1. **期望频数限制**：若任一格子的期望次数小于 5，卡方近似可能不可靠，可考虑：
   - 使用**叶氏连续性修正**（Yates's correction）；
   - 使用**费歇尔精确检验**（Fisher's exact test）。

2. **样本量要求**：卡方检验的卡方分布近似依赖于大样本，样本量过小时结果可能不准确。

## 报告示例

> 卡方检验结果显示，性别与是否使用 AI 工具之间存在显著关联，χ²(1) = 8.42，p < 0.01。其中，男生使用 AI 工具的比例（68.5%）显著高于女生（52.3%）。

## 小结

卡方检验是分析分类变量关联的核心方法。使用时需注意期望频数不小于 5 的前提条件，样本量过小时应改用费歇尔精确检验。报告结果时，应同时给出卡方值、自由度和 p 值。
