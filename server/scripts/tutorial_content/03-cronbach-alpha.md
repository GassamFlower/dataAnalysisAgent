# 信度分析：Cronbach's α

信度（Reliability）是指测量工具的稳定性和一致性。在问卷研究中，最常用的信度指标是 Cronbach's α 系数。

## 什么是 Cronbach's α？

Cronbach's α 用于衡量同一维度下各题目测量同一构念的程度。简单来说，它回答的问题是：这些题目是否在“测同一件事”？

## α 系数的判断标准

| α 值范围 | 信度水平 |
|---------|---------|
| α ≥ 0.9 | 非常优秀 |
| 0.8 ≤ α < 0.9 | 优秀 |
| 0.7 ≤ α < 0.8 | 良好 |
| 0.6 ≤ α < 0.7 | 可接受 |
| α < 0.6 | 不可接受 |

> 一般社会科学研究中，α ≥ 0.7 被认为是可接受的信度标准。

## 影响 α 系数的因素

1. **题目数量**：题目越多，α 通常越高
2. **题目相关性**：题目之间相关性越高，α 越高
3. **反向题处理**：反向题未正确处理会降低 α
4. **样本量**：样本量过小可能导致 α 不稳定

## α 过低怎么办？

如果某个维度的 α 低于 0.7，可以按以下步骤排查：

1. 检查是否有反向题未转换
2. 查看“删除该项后 α 变化”表，考虑删除提升 α 的题目
3. 检查题目表述是否清晰
4. 重新审视维度划分是否合理

## 报告示例

> 学习动机量表包含 8 个题目，Cronbach's α 系数为 0.86，表明该量表具有良好的内部一致性信度。

## 注意事项

- α 高不等于量表好，还需要结合效度分析
- α 不是越高越好，过高的 α（如 > 0.95）可能提示题目冗余
- 不同研究领域对 α 的要求可能略有不同

## 小结

Cronbach's α 是问卷信度检验的基础指标。在论文中报告 α 值时，要同时说明判断标准和你采取的处理措施。
