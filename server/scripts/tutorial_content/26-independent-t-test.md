# 独立样本 t 检验：什么时候用、怎么算、论文怎么写

> **适用人群**：本科毕设 / 问卷实证论文写作者
> **前置知识**：两组比较、p 值、效应量
> **阅读时长**：约 6 分钟
> **学习目标**：判断"两个独立组是否在某连续变量上有差异"时，能用独立样本 t 检验并规范报告结果。

独立样本 t 检验是最常用的差异检验之一——比如"男生和女生的学习动机有没有差别"。这篇讲清楚何时用、前提条件、怎么解读、怎么写。

## 一、什么时候用它

当满足以下条件时用独立样本 t 检验：

- **两个独立组**（如男/女、实验/控制，互不重叠）；
- 比较的因变量是**连续/定距变量**（如李克特量表总分、得分）；
- 检验的是"两组均值是否有显著差异"。

如果比较的是**同一批人的前后测**，用**配对 t 检验**（不是独立样本）。这是最容易混淆的地方。

## 二、前提条件（先检查再跑）

1. **两组数据近似正态**（可用偏度/峰度或 Shapiro-Wilk 看，样本够大时近似正态即可）。
2. **方差齐性**（Levene 检验；不满足时读 Welch 修正的 t 值）。
3. 无严重离群点、样本独立。

> 若连续正态不满足，改用**曼-惠特尼 U 检验**（见「非参数检验」）。用不用非参数：看数据，别为了结果好看乱换。

## 三、结果怎么读

| 统计量 | 说明 |
|--------|------|
| t 值 | 两组均值差异除以标准误，反映差异相对波动的程度 |
| df（自由度） | 一般为 n₁ + n₂ − 2 |
| p 值 | < 0.05 表示差异显著 |
| 组均数与 SD | 报告两组各自的均值与标准差 |
| Cohen's d | 效应量，衡量差异的实际大小（见「效应量」篇） |

判断顺序：**先看 p 是否 < 0.05**；显著再看**效应量 d**来判断差异"客观上大不大"。

## 四、论文写法模板

> 采用独立样本 t 检验比较男女在学习动机上的得分。结果显示，男生组（M=3.62, SD=0.78）与女生组（M=3.41, SD=0.82）差异不显著，t(188)=1.34, p=0.183，效应量 d=0.20。说明性别对学习动机影响不明显。

要点：**均值(M)±标准差(SD)、t、df、p、效应量 d** 五要素齐全即可。显著就写"存在显著差异"，不显著就写"差异不显著"。

## 遇到问题怎么办

- **如果把两组分别做了三次 t 且 p 边缘**：多组 → 学用方差分析 ANOVA 做整体检验，避免"两两比较"导致的重复检验误差。
- **如果方差齐性不满足**：报告到 Welch 修正的 t 值（软件自动给出），而不是硬套齐性 t。
- **如果转学后检验不显著**：回「结果不显著」篇，先查样本量、数据质量、效应量，再如实报告。
- **数据不满足 t 前提（严重偏态）**：改用非参数检验并说明理由，更稳妥。

## 小结

独立样本 t 检验 = 两个独立组的连续变量均值比较。用它前先确认"独立两组 + 连续变量"，跑之前检查前提（方差齐性、正态近似），结果里把 M/SD、t、p、df、d 写全，按显著与否规范描述即可。
