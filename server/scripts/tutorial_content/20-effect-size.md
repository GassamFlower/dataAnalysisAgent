# 效应量与统计功效

效应量（Effect Size）量化研究结果的实际重要性，统计功效（Statistical Power）衡量检验发现真实效应的能力。两者是统计推断中与 p 值同等重要的概念，也是论文报告规范的重要组成部分。

## 效应量（Effect Size）

效应量是量化研究结果**实际重要性**（或差异/关联强度）的统计指标。与 p 值（仅说明差异是否偶然）不同，效应量反映的是**效果的大小**，且不受样本量影响。

### 常见效应量指标

| 指标 | 用途 | 公式 |
|------|------|------|
| **Cohen's d** | 两组均值差异（t 检验） | d = (M₁ − M₂) / SD_pooled |
| **相关系数 r** | 两个连续变量的关联强度 | Pearson 相关 |
| **η²（eta squared）** | 方差分析中自变量解释的变异比例 | η² = SS_效应 / SS_总 |

### 解释标准（Cohen, 1988）

| 指标 | 小效应 | 中效应 | 大效应 |
|------|--------|--------|--------|
| Cohen's d | 0.2 | 0.5 | 0.8 |
| 相关系数 r | 0.1 | 0.3 | 0.5 |
| Eta squared (η²) | 0.01 | 0.06 | 0.14 |

> 效应量不受样本量影响，因此比 p 值更能反映结果的实际意义。即使 p 值显著，若效应量很小，结果的实际意义也可能有限。

## 统计功效（Statistical Power）

统计功效是指在假设检验中，当**备择假设（Hₐ）为真时，正确地拒绝零假设（H₀）的概率**。

> **功效 = Pr(拒绝 H₀ | Hₐ 为真) = 1 − β**

其中 β 为第二类错误（存伪错误）的概率。

### 与两类错误的关系

| 真实情况 | 拒绝 H₀ | 不拒绝 H₀ |
|---------|---------|-----------|
| **H₀ 为真** | 第一类错误（α，弃真） | 正确判断 |
| **Hₐ 为真** | **正确判断（1−β，统计功效）** | 第二类错误（β，存伪） |

## 影响统计功效的因素

统计功效的大小主要受以下四个因素影响：

### 1. 显著性水平（α）

- **关系**：α 与功效呈**正相关**。显著性水平越高，越容易拒绝零假设，功效越高；
- **代价**：提高 α 会增加第一类错误的风险，因此通常设定 α = 0.05 作为平衡点。

### 2. 样本量（n）

- **关系**：样本量越大，功效**越高**。更大的样本能提供更精确的估计，减小标准误，使检验更灵敏；
- **应用**：功效分析常用于计算达到预期功效所需的最小样本量。

### 3. 效应量（Effect Size）

- **关系**：效应量越大，功效**越高**。真实效应越明显，越容易被检测到。

### 4. 变异程度（数据离散度）

- **关系**：数据变异越小，功效**越高**。较小的标准差使统计检验更容易识别出真实差异。

### 四者关系总结

```
功效 = f(α ↑, n ↑, 效应量 ↑, 变异 ↓)
```

| 因素 | 增大时对功效的影响 | 说明 |
|------|-------------------|------|
| 显著性水平 α | 功效 ↑ | 但增加第一类错误风险 |
| 样本量 n | 功效 ↑ | 最常用的提升手段 |
| 效应量 | 功效 ↑ | 由研究设计决定 |
| 数据变异 | 功效 ↓ | 可通过实验设计控制 |

## 功效分析的实际应用

在给定的显著性水平下，功效分析有两种主要用途：

1. **计算所需最小样本量**：给定预期的效应量和目标功效（通常为 0.80），确定研究需要多少样本；
2. **计算可检测的最小效应值**：给定样本量，确定该研究能够可靠检测出的最小效应量。

## 报告示例

> 采用 G*Power 进行先验功效分析，设定 α = 0.05，功效 = 0.80，中等效应量（Cohen's d = 0.5），计算得到每组所需最小样本量为 64 人，两组共需 128 人。

## 小结

效应量反映结果的实际重要性，统计功效衡量检验发现真实效应的能力。报告统计结果时，除了 p 值，还应报告效应量，并在研究设计阶段进行功效分析以确定合适的样本量。这有助于提升研究的科学性和可重复性。
