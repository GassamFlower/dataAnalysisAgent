# 样本量与统计功效

在问卷研究中，样本量直接影响统计检验的可靠性。样本太小可能无法发现真实效应，样本太大则浪费资源。本文介绍样本量与统计功效的核心概念。

## 什么是统计功效？

统计功效（Statistical Power）是指当原假设为假时，正确拒绝原假设的概率。简单来说，就是"发现真实效应的能力"。

$$
\text{Power} = 1 - \beta
$$

其中 $\beta$ 是第二类错误（假阴性）的概率。

| 功效值 | 评价 |
|--------|------|
| Power ≥ 0.80 | 良好（学术界通用标准） |
| 0.50 ≤ Power < 0.80 | 一般 |
| Power < 0.50 | 不足 |

## 影响样本量的四个因素

计算样本量需要考虑以下四个因素：

### 1. 效应量（Effect Size）

效应量反映变量间关系的强弱。效应量越大，所需样本量越小。

- **Cohen's d**（两组均值差异）：$d = \frac{\mu_1 - \mu_2}{\sigma}$
- **Pearson r**（相关）：$r$ 本身即为效应量
- **Cohen's f²**（回归/方差分析）：$f^2 = \frac{R^2}{1 - R^2}$

| 效应量 | d 值 | r 值 |
|--------|------|------|
| 小 | 0.2 | 0.10 |
| 中 | 0.5 | 0.30 |
| 大 | 0.8 | 0.50 |

### 2. 显著性水平（α）

显著性水平是第一类错误（假阳性）的概率上限，通常设为 $\alpha = 0.05$。

### 3. 统计功效（1 - β）

通常希望功效达到 $1 - \beta = 0.80$ 以上。

### 4. 检验方向

- **双侧检验**：不预设方向，更保守，所需样本量更大
- **单侧检验**：预设方向，所需样本量较小

## 常见场景的样本量估算

### 相关分析

对于 Pearson 相关检验，所需样本量近似为：

$$
n \approx \frac{(z_{\alpha/2} + z_{\beta})^2}{\text{arctanh}(r)^2} + 3
$$

经验法则（中等效应量 $r = 0.3$，$\alpha = 0.05$，power = 0.80）：

| 效应量 r | 所需样本量（约） |
|---------|---------------|
| 0.10（小） | 783 |
| 0.30（中） | 84 |
| 0.50（大） | 29 |

### 独立样本 t 检验

每组所需样本量（双侧，$\alpha = 0.05$，power = 0.80）：

| Cohen's d | 每组样本量（约） |
|-----------|--------------|
| 0.2（小） | 394 |
| 0.5（中） | 64 |
| 0.8（大） | 26 |

### 单因素方差分析

每组所需样本量（3 组，$\alpha = 0.05$，power = 0.80）：

| Cohen's f | 每组样本量（约） |
|-----------|--------------|
| 0.10（小） | 322 |
| 0.25（中） | 52 |
| 0.40（大） | 21 |

## 问卷研究的经验法则

对于问卷研究，除了统计功效，还需考虑：

1. **题目数量**：样本量至少为题目数的 5-10 倍（因子分析要求）
2. **缺失值**：预计 10-20% 缺失率，需提前预留
3. **分组分析**：如果需要按人口学变量分组分析，每组至少 30 人
4. **回收率**：问卷回收率通常 30-60%，发送量应为目标样本量的 2-3 倍

> **建议**：本科毕设问卷研究，有效样本量至少 200 份，理想 300 份以上。

## 如何提高统计功效？

如果样本量受限，可以通过以下方式提高功效：

1. **增大效应量**：优化题目设计，减少测量误差
2. **使用配对设计**：配对检验比独立检验功效更高
3. **减少组内变异**：控制额外变量，提高测量精度
4. **使用协变量**：协方差分析（ANCOVA）可减少误差方差

## 常见误区

### 误区 1：样本量越大越好

样本量过大时，即使微不足道的效应也会达到统计显著。此时需结合效应量判断实际意义。

### 误区 2：p 值显著 = 有效应

$p$ 值取决于效应量和样本量的共同影响。小样本下 $p > 0.05$ 不代表没有效应，可能是功效不足。

### 误区 3：事后功效分析可以替代事前规划

事后功效分析受观察效应量影响，可能低估或高估真实功效。应在研究设计阶段进行事前样本量规划。

## 小结

- 统计功效是发现真实效应的能力，目标 ≥ 0.80
- 样本量取决于效应量、显著性水平、功效和检验方向
- 问卷研究建议有效样本 ≥ 200 份
- 样本量规划应在研究设计阶段完成
