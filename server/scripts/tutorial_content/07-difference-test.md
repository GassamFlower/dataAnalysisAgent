# 差异检验：t 检验与方差分析

差异检验用于比较不同群体在某个变量上的得分是否存在显著差异。本科生论文中最常用的差异检验方法是 t 检验和单因素方差分析。

## t 检验

t 检验用于比较两组均值是否存在显著差异。

### 独立样本 t 检验

适用于两组独立样本的比较，例如：

- 男生 vs 女生的焦虑得分
- 实验班 vs 对照班的学习成绩

### 配对样本 t 检验

适用于同一组对象前后两次测量的比较，例如：

- 培训前 vs 培训后的成绩
- 干预前 vs 干预后的满意度

### t 检验的判断标准

- p < 0.05：两组差异显著
- p ≥ 0.05：两组差异不显著

## 单因素方差分析（One-Way ANOVA）

当比较三组或以上的均值时，需要使用方差分析。

### 方差分析的基本思想

将总变异分解为：

- **组间变异**：不同组之间的差异
- **组内变异**：组内个体差异

如果组间变异显著大于组内变异，则说明不同组之间存在显著差异。

### 事后检验

当方差分析结果显著时，需要进行事后检验（如 LSD、Bonferroni、Tukey）来确定具体哪些组之间存在差异。

## 效应量

除了显著性，还应报告效应量：

- t 检验：Cohen's d
- 方差分析：η²（eta squared）

| 效应量 | 小 | 中 | 大 |
|--------|---|---|---|
| Cohen's d | 0.2 | 0.5 | 0.8 |
| η² | 0.01 | 0.06 | 0.14 |

## 报告示例

### t 检验

> 独立样本 t 检验结果显示，男生（M = 3.45，SD = 0.72）与女生（M = 3.82，SD = 0.68）在学习动机上存在显著差异，t(198) = -3.24，p < 0.01，Cohen's d = 0.46。

### 方差分析

> 单因素方差分析结果显示，不同年级学生的学习动机存在显著差异，F(2, 297) = 5.36，p < 0.01，η² = 0.04。事后 Tukey 检验发现，大三学生的学习动机显著高于大一学生（p < 0.05）。

## 小结

t 检验适用于两组比较，方差分析适用于多组比较。报告结果时，除了 p 值，还应包括均值、标准差和效应量，使结果更加完整、可信。
