# 问卷星回收后怎么开始分析：从导出到报告的全流程清单

> **适用人群**：本科毕设 / 问卷实证论文写作者
> **前置知识**：问卷研究基本流程
> **阅读时长**：约 5 分钟
> **学习目标**：拿到问卷星数据后，能按清单一步步完成"导出→清洗→体检→分析→报告"，不遗漏关键环节。

很多同学卡在"数据到手却不知从哪开始"。问卷星只是收集工具，真正的分析在你手上。下面是一条可以直接照着走的工作流。

## 一、导出数据

问卷星「下载答卷数据」时：

- 导出 **Excel/CSV 原始数据**，不要只导出统计报表。
- 勾选**包含题目文本与选项原文**，方便核对反向题。
- 注意导出的是"每一行一个人"的长表结构（重要：一行一名受访者，一列一道题）。

## 二、数据清洗（最容易被跳过的关键一步）

1. **删除无效问卷**：用时过短、全选同一选项（直线作答）、明显乱填的。
2. **处理缺失值**：缺失过多（如超过 20%）的受访者考虑删除；单个空缺可考虑填均值或做删除。
3. **找出并处理异常值 / 离群点**。
4. **反向题记得反向计分**：在导入前或分析中把反向题的分数翻转过来。
5. **检查题型导出格式**是否与你的分析结构一致。

## 三、题目体检

把清洗好的题目结构（题型、维度归属、反向题标记）交给系统核对，确保后续分析按正确结构跑。这一步帮你提前发现"我漏了反向题""某题我标错维度"这类低级但致命的问题。

## 四、分析

按论文问题走标准流程：

1. 描述性统计（均值、标准差、频数）
2. 信度（Cronbach's α）
3. 效度（KMO / Bartlett，必要时因子分析）
4. 相关分析 / 差异检验 / 回归（按你的研究假设）

每一步都在报告里看结果，未达标回「信效度不达标」篇处理。

## 五、生成报告并导出

分析完成后，把关键结果（信效度、相关矩阵、差异检验）按规范写进论文。可用系统的报告导出功能生成给导师看的版本，节省排版时间。

## 遇到问题怎么办

- **如果导出的数据格式看不懂**：先确认勾选了"原始数据"，并理解"一行一人、一列一题"；拿前 5 行手工核对一下。
- **如果存在大量缺失 / 无效问卷**：回到「样本量」那篇，按回收率公式判断是否要补发。
- **如果反向题没标、导致 α 低或相关被抵消**：回「信效度/不显著」篇先处理后重跑。
- **如果时间紧、需要快速出可用结果**：优先保证清洗 + 反向题 + 信效度达标这三件事，再谈相关与假设检验。

## 小结

问卷星只是收集入口。拿到数据后按「导出原始数据 → 清洗 → 题目体检 → 分析 → 报告导出」五步走，前两步特别是清洗和反向题务必做扎实。流程对了，出报告和写论文都会顺畅很多。
