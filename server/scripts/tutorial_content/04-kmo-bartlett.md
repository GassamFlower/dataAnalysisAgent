# 效度分析：KMO 与 Bartlett 检验

效度（Validity）是指测量工具能够准确测量其所要测量构念的程度。在结构效度分析中，KMO 检验和 Bartlett 球形检验是进行因子分析前的必要步骤。

## 什么是结构效度？

结构效度关注量表的理论结构是否与实际数据相符。通过因子分析，可以检验：

- 各题目是否归属于预期的维度
- 维度之间的区分是否清晰
- 量表结构是否稳定

## KMO 检验

KMO（Kaiser-Meyer-Olkin）衡量样本数据的充足性，用于判断数据是否适合进行因子分析。

### 判断标准

| KMO 值 | 适合程度 |
|--------|---------|
| ≥ 0.9 | 非常适合 |
| 0.8-0.9 | 很适合 |
| 0.7-0.8 | 适合 |
| 0.6-0.7 | 不太适合 |
| < 0.5 | 不适合 |

## Bartlett 球形检验

Bartlett 球形检验用于检验变量之间是否存在相关性。

- **原假设 H₀**：变量之间相互独立
- **判断标准**：p 值 < 0.05 时，拒绝原假设，说明变量间存在显著相关，适合进行因子分析

## 分析步骤

1. 进行 KMO 和 Bartlett 检验
2. 判断是否适合因子分析
3. 进行探索性因子分析（EFA）
4. 根据因子载荷判断题目归属
5. 必要时删除载荷不清晰的题目

## 常见问题

### KMO 值过低

可能原因：

- 样本量不足
- 变量间相关性较弱
- 题目与维度不匹配

### Bartlett 检验不显著

可能原因：

- 变量间确实相互独立
- 数据不适合做因子分析
- 需要重新审视量表结构

## 报告示例

> KMO 值为 0.84，Bartlett 球形检验 χ² = 1256.32，p < 0.001，表明数据适合进行因子分析。探索性因子分析结果显示，各题目在其所属维度上的因子载荷均大于 0.5，量表结构效度良好。

## 小结

KMO 和 Bartlett 检验是效度分析的“入场券”。只有通过了这两项检验，后续的因子分析结果才具有说服力。
