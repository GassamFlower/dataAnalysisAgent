# 论文中常用的统计表述规范

规范的统计表述能够提升论文的专业性和可读性。本节总结本科生论文中常见的统计表述规范。

## 数字与符号格式

### 小数位数

- 均值、标准差：通常保留两位小数
- 相关系数：通常保留两位或三位小数
- p 值：通常保留三位小数，或按 p < 0.05 / p < 0.01 / p < 0.001 报告

### 示例

- M = 3.82，SD = 0.64
- r = 0.65，p < 0.01
- β = 0.42，p < 0.001

## 常用统计符号

| 符号 | 含义 | 示例 |
|------|------|------|
| M | 均值 | M = 3.82 |
| SD | 标准差 | SD = 0.64 |
| r | Pearson 相关系数 | r = 0.65 |
| t | t 检验统计量 | t(198) = 3.24 |
| F | 方差分析统计量 | F(2, 297) = 5.36 |
| p | 显著性水平 | p < 0.05 |
| β | 标准化回归系数 | β = 0.42 |
| R² | 决定系数 | R² = 0.33 |
| η² | 效应量 | η² = 0.04 |
| Cohen's d | 效应量 | d = 0.46 |

## 显著性表述

| p 值 | 表述 |
|------|------|
| p < 0.001 | 差异/关系极其显著 |
| p < 0.01 | 差异/关系非常显著 |
| p < 0.05 | 差异/关系显著 |
| p ≥ 0.05 | 差异/关系不显著 |

> 注意：现在越来越多的期刊建议使用具体 p 值，并配合效应量解释。

## 95% 置信区间

在可能的情况下，报告 95% 置信区间（95% CI）：

> 学习动机对学业成绩影响的 95% 置信区间为 [0.25, 0.59]。

## 避免的错误表述

### ❌ 错误

- p = 0.000
- 相关很显著说明因果
- 差异显著说明效果很大

### ✅ 正确

- p < 0.001
- 相关显著，但不能推断因果
- 差异显著，但效应量较小

## 中文论文中的英文符号

在中文论文中，统计符号通常保留英文形式，但 surrounding text 用中文：

> 学习动机的均值为 3.82（SD = 0.64），表明样本整体学习动机处于中等偏上水平。

## 小结

规范的统计表述是论文写作的基本功。建议在写作过程中建立统一的格式标准，并全文保持一致。
