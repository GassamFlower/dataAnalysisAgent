# 描述性统计与正态性检验

描述性统计是数据分析的第一步，它能够帮助我们快速了解数据的基本特征和分布形态。

## 常用的描述性统计量

### 集中趋势

- **均值（Mean）**：所有数据的算术平均数，反映数据的平均水平
- **中位数（Median）**：将数据排序后位于中间的值，不受极端值影响
- **众数（Mode）**：出现频率最高的值

### 离散趋势

- **标准差（Standard Deviation）**：反映数据的离散程度
- **方差（Variance）**：标准差的平方
- **全距（Range）**：最大值与最小值之差

### 分布形态

- **偏度（Skewness）**：反映分布的不对称程度
- **峰度（Kurtosis）**：反映分布的尖锐程度

## 正态性检验

许多统计方法（如 t 检验、方差分析）都假设数据服从正态分布。因此，正式分析前需要检验正态性。

### 常用的正态性检验方法

1. **Shapiro-Wilk 检验**：适用于小样本（n < 50）
2. **Kolmogorov-Smirnov 检验**：适用于大样本
3. **Q-Q 图**：直观判断数据是否近似正态分布
4. **偏度和峰度**：偏度接近 0、峰度接近 3 说明近似正态

### 判断标准

- p 值 > 0.05：不能拒绝正态分布假设
- p 值 < 0.05：数据偏离正态分布

## 数据不服从正态分布怎么办？

如果数据明显偏离正态分布，可以考虑：

1. 检查异常值并处理
2. 对数据进行转换（如对数转换）
3. 使用非参数检验方法
4. 增加样本量（大样本下中心极限定理适用）

## 报告示例

> 学习动机量表的总均分为 3.82（SD = 0.64），偏度为 -0.32，峰度为 -0.18，Shapiro-Wilk 检验显示数据近似服从正态分布（W = 0.98，p = 0.21）。

## 小结

描述性统计虽然简单，但它是后续所有复杂分析的基础。在论文中，描述性统计结果通常以表格形式呈现，方便读者快速把握数据全貌。
