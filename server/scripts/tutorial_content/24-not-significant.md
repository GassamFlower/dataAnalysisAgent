# 统计结果不显著怎么办：p > 0.05 的排查清单

> **适用人群**：本科毕设 / 问卷实证论文写作者
> **前置知识**：假设检验、p 值含义
> **阅读时长**：约 6 分钟
> **学习目标**：当相关性、差异检验或回归不显著时，能按清单定位原因并决定补救或如实报告。

"我预期显著却不显著，是不是论文要废了？"——不，这是论文工作里最常见的情况之一。先搞清楚：**不显著 ≠ 没研究意义**，可能是统计功效不足、数据质量或假设本身设定的问题。

## 一、先分清"是不是真没效应"

p > 0.05 有两种可能：

1. 真没效应（研究假设不成立）。
2. **有效应但没检测出来**（功效不足、样本太小、噪声太大）。

**区分两者的关键**是统计功效和效应量，而不是直接判死刑。样本少 + p 接近 0.05 时，多半是"功效不足"而非"没有效应"。

## 二、常见的六个原因与对应排查

| 原因 | 表现 | 对策 |
|------|------|------|
| 样本量太小 | p 在 0.05~0.4 之间游走 | 补样本，或合并分组 |
| 异常值 / 缺失值 | 统计量被个别点拉偏 | 回到「数据清洗」篇 |
| 反向题没处理 | 均值和相关被抵消 | 核对反向计分 |
| 效应量本来就小 | 即使相关显著意义也有限 | 换更大样本，或如实报告 |
| 问卷题目信度低 | 测量噪声大 | 提升信度后再比 |
| 分组本身差异很小 | 两组其实差不多 | 合理，按此结论写 |

## 三、最常见的救命操作

1. **先清洗数据**：去掉乱填、直线作答、异常离群值，再做一次分析，常能救回不显著。
2. **核对反向题**：一张问卷反向题没反，直接毁掉相关。改完重跑。
3. **检查样本功效**：如果你只想检测"中等效应"而样本每组才 30，永远达不到显著。回到「样本量多少才够」按目标补样本（如果能补的话）。
4. **换更合适的检验**：如非参数检验（当数据不满足正态）。但换说法开放要诚实，不要为了显著而换检验。

## 四、如果确实救不回来

说不出好改的，别硬凑。诚实报告是学术底线：

- 在结果里如实写"未发现显著差异 / 相关（p > 0.05）"，并解释可能的原因（样本量、效应量、测量误差）。
- 把"不显著的发现"和"为什么可能"写进讨论，这本身就是一个可接受的结论。

> 绝对不要：改数字、删掉不显著的样本、只挑显著的结果报告。这是学术不端，一查一个准。

## 遇到问题怎么办

- **如果 p 在 0.05~0.1（边缘）且样本这次不够**：优先补样本或补功效分析，说明再加大样本可能达到显著，比直接当"没有"处理稳妥。
- **如果导师指望必须显著**：坦率讨论——追问原因是否可救（补样本 / 清洗 / 反向题），能救则救；实在不能显著的，走"诚实+讨论"路线，这比造假安全得多。
- **如果你在报告里看到诊断提示了具体问题**：先按提示（如某维度 α 低、样本不足）处理完再重跑，通常能解决大部分"不显著"。
- **写进论文的句式**："结果显示，X 与 Y 之间未发现显著相关（r = …, p = …），可能原因包括样本量有限或测量误差较大。" 这话没毛病。

## 小结

遇到不显著：先查数据质量（清洗、反向、离群）→ 再查样本功效 → 合理换检验方法 → 确实无效应时如实报告并在讨论里给原因。千万别造假。绝大部分"不显著"都能在动手清理 + 补齐样本后明确走向。
