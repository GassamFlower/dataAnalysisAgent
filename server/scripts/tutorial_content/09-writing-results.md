# 如何撰写数据分析结果

数据分析结果部分是论文的核心内容之一。写好结果部分，需要做到逻辑清晰、数据准确、解释到位。

## 结果部分的基本结构

1. **样本特征描述**：介绍样本量、性别、年龄等基本信息
2. **描述性统计**：报告各变量的均值、标准差等
3. **信效度检验**：报告 Cronbach's α、KMO、Bartlett 等
4. **相关分析**：展示变量间相关关系
5. **差异检验或回归分析**：报告主要研究假设的检验结果

## 撰写原则

### 1. 先总体后具体

先描述整体数据特征，再逐步深入到具体假设检验。

### 2. 数据与解释结合

不要只罗列数字，要对结果进行解释：

- 这个结果说明什么？
- 与研究假设是否一致？
- 有什么实际意义？

### 3. 使用规范的统计符号

- 均值和标准差：M (SD)
- 相关系数：r
- t 检验：t(df) = ...
- 方差分析：F(df1, df2) = ...
- p 值：p < 0.05，p < 0.01，p < 0.001

## 常用句式

### 描述样本

> 本研究共回收有效问卷 320 份，其中男生 142 人（44.4%），女生 178 人（55.6%）。

### 描述性统计

> 学习动机量表的总均分为 3.82（SD = 0.64），处于中等偏上水平。

### 相关分析

> 学习动机与学业成绩呈显著正相关（r = 0.65，p < 0.01）。

### 回归分析

> 多元线性回归分析结果表明，学习动机对学业成绩有显著正向预测作用（β = 0.42，p < 0.001）。

## 表格呈现

复杂的结果建议用表格呈现，例如：

| 变量 | M | SD | 1 | 2 | 3 |
|------|---|---|---|---|---|
| 1. 学习动机 | 3.82 | 0.64 | 1 | | |
| 2. 学习策略 | 3.65 | 0.71 | 0.58** | 1 | |
| 3. 学业成绩 | 82.45 | 8.32 | 0.65** | 0.52** | 1 |

> ** p < 0.01

## 避免的常见错误

1. 结果部分加入过多讨论和解释
2. 只报告显著的结果，忽略不显著的结果
3. 统计符号使用不规范
4. 表格内容重复正文描述

## 小结

结果部分要客观、准确地呈现数据分析发现，避免过度解释。讨论部分才是你对结果进行深入分析和理论解释的环节。
