# 量表维度怎么划分才合理：理论驱动 + 因子分析校验

> **适用人群**：本科毕设 / 问卷实证论文写作者
> **前置知识**：信效度未达标时反看维度归属
> **阅读时长**：约 6 分钟
> **学习目标**：学会用「理论依据 + 数据校验」两把尺子，合理地把题目归入维度，而不是随意捏合。

"这些题该放哪个维度"看起来很主观，其实有清晰的判断顺序。好的维度划分是**先有理论、再拿数据验证**，而不是先跑出来再硬解释。

## 一、原则：理论优先，数据校验

正确的顺序：

1. **先看文献**：尽量采用成熟量表的分维方式——最有说服力的是复用已有量表，而不是自己脚写十几个新题硬凑维度。
2. **然后明确每个维度测什么**：给每个维度写清"它测量的核心构念"，同维度的题目都应该围绕这一个构念。
3. **最后才用因子分析校验**：看这一套分组在实际数据里是否站得住。

> 反例：先跑出几个因子，再反过来给每个因子"编"一个名字去自圆其说。这在答辩时很容易被拆穿。

## 二、理论驱动怎么分

判断一组题目是否属于同一个维度，问三个问题：

- 它们在**语义上**是不是在问同一件事？（同义、同方向）
- 它们的**测量尺度**是否一致？（都是 5 点李克特等）
- 它们测的是`态度/能力`，还是`行为/事实`？（通常要分开）

满足越多，归入同一维度的理由越足。

## 三、用因子分析校验维度

当你有了理论归属后，用探索性因子分析（EFA）验证：

| 指标 | 说明 | 合理区间 |
|------|------|---------|
| KMO | 是否适合做因子分析 | ≥ 0.7 |
| Bartlett p | 变量间相关性 | < 0.05 |
| 特征值 | 决定取几个因子 | > 1 |
| 因子载荷 | 一题与所属因子的相关 | 建议 ≥ 0.5 |
| 交叉载荷 | 一题同时在多个因子都高 | 越低越好 |

**判断维度好坏的核心**：每个题目应当在它所属因子上载荷高（>0.5），在其它因子上载荷低（理想 <0.3）。如果一个题"脚踩两条船"（交叉载荷高），说明它的归属不清晰，要么改写，要么换题。

## 四、做不下去的三种情况

1. **某题在任何因子上载荷都低**：这题和所有人都不相关，考虑删除，而不是硬塞。
2. **两个维度高度相关（r > 0.85）**：可能它们其实是同一个维度，考虑合并。
3. **理论上是分开的，数据却揉成一团**：检查是否反向题没处理、题目表述是否有歧义，再决定是否按理论坚持（要有合理解释）。

## 遇到问题怎么办

- **如果理论归类和因子分析结果不一致**：优先查数据质量（反向题、表述歧义）后再重跑；仍未解决则在论文里如实说明，并给出"以理论为主、因子分析为辅"的处理理由。不要为了凑数硬改维度。
- **如果因子分析提取的因子比预期的多或扫**：这里的"扫"指边界模糊、因子间区分度不足，可用特征值 ≥1、碎石图、以及"能不能给出构念解释"来辅助判断因子数量，切忌纯看数字。
- **如果导师要求复用成熟量表**：直接照搬并注明量表来源与适用人群，这是最稳妥的维度数法，也是很多本科论文采用的方式。

## 小结

维度划分 = 理论依据（尽量复用成熟量表 + 明确构念）→ 数据校验（EFA 的载荷 / 交叉载荷）→ 必要时微调删除或合并。先理论后数据，论文里才有说服力，答辩也不怕被追问。
