# 相关分析

相关分析用于研究两个变量之间的线性关系，是问卷研究中最基础、最常用的分析方法之一。

## 相关系数 r

Pearson 相关系数 r 的取值范围是 -1 到 1：

- **r = 1**：完全正相关
- **r = -1**：完全负相关
- **r = 0**：无线性相关

## 相关强度的判断

| \|r\| 范围 | 相关强度 |
|-----------|---------|
| 0.00-0.19 | 极弱相关 |
| 0.20-0.39 | 弱相关 |
| 0.40-0.59 | 中等相关 |
| 0.60-0.79 | 强相关 |
| 0.80-1.00 | 极强相关 |

## 使用条件

Pearson 相关分析要求：

1. 两个变量都是连续变量
2. 变量间存在线性关系
3. 数据近似正态分布
4. 无明显异常值

如果不满足这些条件，可以考虑 Spearman 秩相关。

## 相关不等于因果

这是相关分析中最重要的原则：

- 相关只说明两个变量同时变化
- 不能说明一个变量导致另一个变量变化
- 可能存在第三变量同时影响两者

## 结果解读示例

| 变量 | 学习动机 | 学业成绩 |
|------|---------|---------|
| 学习动机 | 1 | |
| 学业成绩 | 0.65** | 1 |

> ** 表示 p < 0.01

解读：学习动机与学业成绩呈显著正相关（r = 0.65，p < 0.01），即学习动机越强，学业成绩倾向于越高。

## 常见错误

1. 将相关关系解释为因果关系
2. 忽视异常值对相关系数的影响
3. 对分类变量误用 Pearson 相关
4. 只看显著性，不看效应量

## 小结

相关分析是探索变量关系的有力工具，但要谨慎解释。在论文中，相关分析结果通常以相关矩阵表呈现，并标注显著性水平。
