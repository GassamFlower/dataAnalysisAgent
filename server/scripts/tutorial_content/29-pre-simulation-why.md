# 发问卷前为何先预演

问卷研究最怕的不是分析不会，而是**发出去收不回来、收回来又不达标、假设跑不出来**。很多人等到回收结束、答辩只剩两周才跑 SPSS，发现 α 系数太低、维度划分有问题、相关性不显著，已经来不及重新发放，只能硬着头皮写。所谓「预演」，就是**在正式发问卷之前，先用题目结构 + 假设方向 + 假定样本量，把整条统计流水线先"跑"一遍**，提前知道方向对不对、要收多少人。

## 预演是什么

预演不是真的发问卷，而是**回收前的模拟**：把你设计的量表题目、拟检验的假设、以及你打算回收的样本量作为输入，生成一批符合你设定结构的模拟数据，再走一遍信度、效度、相关、差异检验这些统计流程。

你在回收前就能看到三件事：

1. **信效度方向**：这套题目按你预期的维度划分，Cronbach's α / KMO 大致是什么水平，会不会一跑就红。
2. **假设能不能成立**：给定你预想的效应量（相关强弱）与样本量，这条关系的检出概率（命中率/统计功效）有多少。
3. **样本量够不够**：要达到理想功效，每组至少要收多少人，回收目标提前定下来。

## 为什么要预演

### 1. 提前暴露设计问题，而不是回收后才发现

题目的维度归属、反向题标记、表述歧义，这些在正式分析前基本就能暴露。预演阶段发现问题，改的是题目设计——成本极低；回收后发现问题，改的是整份问卷——只能重发。

### 2. 先把"假设方向"验一验

很多核心假设（比如"工作压力负向预测离职意向"）在真实回收里跑不出来，往往不是数据造假，而是**效应本来就弱或样本不够**。预演用功效分析先算清楚：在当前效应量与样本量下，这条关系有多大把握被检出。方向不对、力度不足，在发问卷之前就能判断。

### 3. 把回收目标定量化

预演能倒推出来的最有用的一件事是：**要达到可接受功效，需要回收多少样本**。避免两种极端——收太少导致结果不稳定，或盲目多收、浪费精力和经费。

### 4. 答辩时有"预防针"

预演记录了你对效应量、样本量的先验设定和每一步的调整依据。答辩被问"你怎么确定样本量 / 为什么这条假设不显著"时，你能清晰回答这是**设计阶段就评估过功效**的方法学安排，而不是事后补救。

## 预演三步走

以典型问卷研究为例：

1. **题目体检**：上传问卷题目，确认题型、维度归属与反向题标记是否正确。
2. **设定假设与期望**：一句话描述你要检验的关系方向，并给出预期的效应强弱。
3. **看命中率**：系统结合样本量计算每条假设的命中性（统计功效），指出不达标的路径，并给出"加样本 / 提高效应"的调整建议。

## 怎么进入预演

创建研究项目后选择**「数据预演」**入口，按上面三步操作即可。预演结果只用于**回收前的方法学评估**，帮助你决定题目与样本量是否该调整。

## 合规小贴士

预演生成的是**模拟数据**，结论仅供**学习和研究参考**，不得作为正式学术论文的数据来源或研究结论。正式研究请务必基于真实回收数据重跑分析。
