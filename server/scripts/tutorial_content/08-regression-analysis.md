# 回归分析基础

回归分析用于研究一个或多个自变量对因变量的预测作用，是问卷研究中探索因果关系的重要方法。

## 线性回归的基本形式

简单线性回归方程：

```
Y = β₀ + β₁X + ε
```

其中：

- Y：因变量
- X：自变量
- β₀：截距
- β₁：回归系数
- ε：误差项

## 多元线性回归

当存在多个自变量时，使用多元线性回归：

```
Y = β₀ + β₁X₁ + β₂X₂ + ... + βₙXₙ + ε
```

## 常用的判断指标

### R²（决定系数）

表示自变量解释因变量变异的比例。

- R² = 0.30：自变量解释因变量 30% 的变异
- R² 越接近 1，模型拟合越好

### 回归系数 β

表示自变量每变化一个单位，因变量变化多少。

- β > 0：正向影响
- β < 0：负向影响

### 显著性 p 值

- p < 0.05：该自变量对因变量有显著预测作用

## 回归分析的假设

1. 线性关系
2. 残差正态分布
3. 残差方差齐性
4. 自变量间不存在严重多重共线性
5. 观测值相互独立

## 多重共线性

当自变量之间高度相关时，会出现多重共线性问题。可以通过 VIF（方差膨胀因子）判断：

- VIF < 5：无严重共线性
- VIF ≥ 10：存在严重共线性

## 结果解读示例

> 以学业成绩为因变量，以学习动机、学习策略为自变量进行多元线性回归分析。结果显示，模型显著，F(2, 197) = 48.32，p < 0.001，R² = 0.33。学习动机（β = 0.42，p < 0.001）和学习策略（β = 0.28，p < 0.001）均对学业成绩有显著正向预测作用。

## 常见错误

1. 将相关变量全部放入回归模型，不进行筛选
2. 忽视多重共线性问题
3. 忽略回归假设的检验
4. 将回归结果直接解释为因果关系

## 小结

回归分析能够揭示变量间的预测关系，但要注意满足基本假设，并谨慎解释因果。在论文中，回归结果通常以表格形式详细报告。
