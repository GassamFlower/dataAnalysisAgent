# 中介效应分析

中介效应分析用于解释自变量（X）与因变量（Y）之间关系背后的机制。当自变量并非直接导致因变量的变化，而是通过影响第三个变量（中介变量 M），再由中介变量影响因变量时，就存在中介效应。

## 中介效应的概念

中介效应模型的核心路径为：

**X → M → Y**

即：自变量影响中介变量，中介变量进而影响因变量。

例如：父母教养方式（X）通过影响自我效能感（M），进而影响学习投入（Y）。这里的自我效能感就是中介变量。

## 直接效应与间接效应

- **总效应（Total Effect, c）**：自变量对因变量的总影响；
- **直接效应（Direct Effect, c'）**：控制中介变量后，自变量对因变量的直接影响；
- **间接效应（Indirect Effect, ab）**：自变量通过中介变量对因变量的影响，即路径 a × 路径 b 的乘积。

在线性系统中：**总效应 = 直接效应 + 间接效应**（c = c' + ab）。

## 因果步骤法（Baron & Kenny, 1986）

这是经典的中介效应检验方法，包含三个步骤：

| 步骤 | 内容 | 回归方程 | 判定标准 |
|------|------|----------|----------|
| **步骤1** | 因变量对自变量回归 | Y = β₁₀ + β₁₁X + ε₁ | β₁₁ 显著 |
| **步骤2** | 中介变量对自变量回归 | M = β₂₀ + β₂₁X + ε₂ | β₂₁ 显著 |
| **步骤3** | 因变量同时对中介变量和自变量回归 | Y = β₃₀ + β₃₁X + β₃₂M + ε₃ | β₃₂ 显著；β₃₁ 的绝对值应小于步骤1中的 β₁₁ |

> 注意：Hayes（2009）指出，步骤1并非必需——即使总效应不显著，中介效应仍可能存在（称为"不一致中介"）。

## Sobel 检验

Sobel 检验用于判断中介效应（间接效应 ab）是否显著不为零。

公式：

```
z = ab / √(b²sₐ² + a²s_b²)
```

其中 a = 自变量对中介变量的回归系数，b = 中介变量对因变量的回归系数，sₐ、s_b 为对应的标准误。

**局限性**：
- 假设抽样分布为正态分布；
- 统计功效较低，需要较大样本量。

## Bootstrap 方法（推荐）

Bootstrap 方法是 Sobel 检验的替代方案，也是当前检验中介效应最流行的方法。

**优势**：
- 非参数检验，不要求正态分布假设；
- 统计功效更高，尤其适用于小样本；
- 操作原理：从数据集中有放回地重复随机抽样，计算每次重抽样中的统计量，通过数百或数千次重抽样近似得到统计量的抽样分布。

**判定标准**：若 Bootstrap 置信区间不包含 0，则中介效应显著。

> 当前，Bootstrap 已成为检验中介效应最流行的方法，而基于 Baron & Kenny 步骤或 Sobel 检验的纯方法已越来越难以发表。

## 完全中介与部分中介

| 类型 | 定义 |
|------|------|
| **完全中介** | 加入中介变量后，自变量与因变量之间的关系降至零 |
| **部分中介** | 中介变量解释了部分（而非全部）自变量与因变量的关系，直接效应仍然存在 |

> 重要提示：Hayes 等学者建议放弃"完全/部分中介"的术语，因为中介效应是否显著应通过统计检验（如 Bootstrap）来确定，而非仅凭系数变化判断。

## 报告示例

> 采用 Bootstrap 法（5000 次重抽样）检验自我效能感在父母教养方式与学习投入之间的中介效应。结果显示，间接效应为 0.12，95% 置信区间为 [0.05, 0.21]，不包含 0，表明中介效应显著。控制中介变量后，直接效应为 0.18（p < 0.05），说明自我效能感起部分中介作用。

## 小结

中介效应分析用于揭示自变量影响因变量的内在机制。检验中介效应时，推荐使用 Bootstrap 方法，因为它不依赖正态分布假设且统计功效更高。报告时应给出间接效应值及其置信区间。
