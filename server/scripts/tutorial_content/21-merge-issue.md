# 问卷信效度不达标怎么办：从排查到修改的完整流程

> **适用人群**：本科毕设 / 问卷实证论文写作者
> **前置知识**：信度、效度的基本概念与判断标准
> **阅读时长**：约 6 分钟
> **学习目标**：当 Cronbach's α 过低、KMO 偏低或 Bartlett 不显著时，能按流程定位问题并给出可落地的修改建议。

拿到分析报告，最常遇到的情况就是"信效度不达标被导师打回来"。别慌，几乎所有不达标都有明确原因和对应解法。下面按最常见的三种情况逐个排查。

## 一、Cronbach's α 过低（常见 < 0.7）

α 系数衡量同一维度下各题目是否测的是同一个东西。

| α 范围 | 结果 | 通常做法 |
|--------|------|---------|
| α ≥ 0.8 | 优秀 | 无需处理，直接报告 |
| 0.7 ≤ α < 0.8 | 良好 | 直接报告 |
| 0.6 ≤ α < 0.7 | 尚可 | 检查「删题后 α 提升」项，酌情删 1-2 题 |
| α < 0.6 | 不合格 | 必须删题或调整维度 |

### 常见原因与对策

1. **题目表述不清 / 语义反了**：同一维度里混进了语义相反的题。逐个读一遍题面，看是否都在"一个方向"打勾。
2. **反向计分题没处理**：设有反向题但没做反向编码。先确认数据问卷是否已反向计分。
3. **某个题与整体无关**（item-total correlation 很低）：把该题删掉，α 会明显回升。优先删「删题后 α 提升最大」的那一题，每次删一题重跑。
4. **维度划分不合理**：本应属于两个维度的题被放在了一起。这时需回到「量表维度怎么划分才合理」那篇，重新审视归属。

> **经验顺序**：先查反向题 → 再查表述歧义 → 再逐题看「删后 α」→ 最后考虑拆维度。千万不要一上来就急着重发问卷。

## 二、KMO 偏低（常见 < 0.6）

KMO 衡量样本是否足够、偏相关够不够，用于判断适不适合因子分析。

| KMO | 结论 |
|-----|------|
| ≥ 0.8 | 非常适合 |
| 0.7~0.8 | 适合 |
| 0.6~0.7 | 勉强，可以接受 |
| 0.5~0.6 | 不太合适 |
| < 0.5 | 不合适 |

### 常见原因与对策

- **样本量不足**：KMO 对样本敏感，先确认样本量是否到了题目数的 5-10 倍。
- **某题单独很高**：个别题与其它题整体相关低，KMO 会被拉低。在相关性矩阵里找与所有题都不相关的"孤立题"，考虑删除，KMO 会上升。
- **维度本身就不该放一起做因子分析**：如果题目跨越多个领域，KMO 会低。此时应**按维度分别做**，而不是整份问卷一起做。

## 三、Bartlett 球形检验不显著（p > 0.05）

Bartlett 检验变量间整体相关是否显著。p > 0.05 代表**变量间没有足够相关**，说明做因子分析的基础不足。

### 常见原因与对策

1. **样本太小**，相关估计不稳定。先加大样本。
2. **题目间确实几乎无关**：说明这些题彼此独立，结构效度难以建立。重新审视维度设计，确保同维度的题测量的确实是一个概念。
3. **数据质量差**（大量缺失、异常值）：回到「数据清洗」篇先清理。

## 遇到问题怎么办

- **如果你的报告 α 在 0.6~0.7 之间，只差一点点**：先按上述删除孤立题、核对反向题，多数情况能拉到 0.7 以上；不要直接改数字，导师会查原题生成。
- **如果删题后仍不达标**：说明维度归属本身有问题，回到「量表维度怎么划分」重新整合题目，而不是硬留不相关题目拉低信度。
- **如果 KMO 和 Bartlett 一起不达标且样本已足够**：大概率是题目跨领域，改成按维度分别做效度分析。
- **修改后必须重跑一遍完整报告**：确认 α / KMO / Bartlett 三者都达标并记录最新数值再写进论文。

## 小结

信效度不达标是流程问题，不是"死局"。先查反向题和数据清洗 → 再逐题删除看「删后 α」→ 必要时重新划分维度 → 补足样本量 → 按维度分别做效度。一套流程走完，绝大多数问卷都能救回来。
